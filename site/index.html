How the score is built

Indicator weights

    1. The four activity indicators are divided by the district's population, so large and small districts can be compared. Literacy is already a rate.
    2. Within each year, every indicator is rescaled so the lowest district is 0 and the highest is 1 (min-max normalisation).
    3. The five rescaled values are multiplied by the weights above, added up, and multiplied by 100. A missing indicator counts as 0.
    4. Districts are ranked by score nationally and inside their state.

    Because the rescaling is done separately for each year, a score shows where a district stands against the others that year, not absolute growth.

    Where the data comes from

    The list of districts and states is real, taken from a community-maintained registry of official Indian districts. The metric values are synthetic: they are generated with fixed random seeds at realistic national magnitudes, with deliberate errors added so the cleaning pipeline has real work to do.

    The pipeline is Python and PostgreSQL. The code, the SQL that computes the index and the exported files are in the project repository.
